# 第9周实验配套代码

本目录由Codex进行AI辅助重构与测试生成。任务2的tests/manual.test.ts由徐楠在AI逐步指导下录入并手动运行，5条基础测试全部通过。

在本目录执行：

```powershell
npm ci
npm run typecheck
npm run test
npm run build
```

完成构建后，用任意静态HTTP服务器打开index.html。页面沿用第8周的外观，保留添加、切换、筛选、编辑、删除和本地存储功能。源代码在src，构建输出在dist。

业务契约：文本trim后长度1至200个UTF-16代码单元；允许同名任务但ID唯一；ID为正安全整数；未知ID无副作用；无效存储记录过滤，损坏JSON回退空数组；存储不可用时显示提示并保留本次页面的内存操作。

tests/manual.test.ts包含任务2手动操作的5条测试，tests/basic.test.ts包含5条AI辅助基础参考测试，tests/boundaries.test.ts包含37条补充测试。Prompt.md记录测试生成约束。共3个测试文件、47条用例。

仓库地址：https://github.com/XuNan-qing/web-week7-todo 。第9周源码位于“第9周实验报告/todo-ts”，依赖和构建输出通过.gitignore排除。实验报告与本地核验材料单独保存在电脑上。
